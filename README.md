## 1. 企画の核（既決事項）

- 名称：**MATCHA ROUTE**
- キャッチコピー：**知らない抹茶に、会いに行こう。**
- 初回テーマ：**まだ知らない、抹茶の10のかたち。**
- 最優先の価値：**まだ知らない抹茶のおいしさや魅力に出会い、自分の「好き」を広げること。**
- 商品選定：**「おいしそう」「食べてみたい」**を第一にする。珍しさ・驚きは必須ではなく、一般的なプリン・ケーキ・アイス等も扱う。
- DISCOVERY POINT：味わいや食感、見た目、素材、作り手、食べ方等の**小さな発見**。検証できない味の断定や実食レビューはしない。
- Webは**無料・購入任意**。商品を知り、保存するだけでも楽しめる。
- 継続利用の中心は**テーマ別の発見（B案）**。再訪問への効果は未検証。
- POP-UPはWebを置き換えるものではなく、丸井グループと連携できた場合の**実物との出会い**への拡張。

## 2. 想定利用者・差別化

- 第一対象：抹茶スイーツが好きで、新しい商品にも関心がある人。年齢・性別などを根拠なく限定しない。
- 第二対象：抹茶にあまり親しみがない人。初期段階では第一対象での価値検証を優先。
- SNSやECでも偶然の発見はできる。差別化の仮説は**「抹茶に特化したテーマ編集」「1商品ずつの写真中心の体験」「保存」「将来の実店舗との接続」**であり、競合優位性は実証されていない。
- 将来の集客はSNSのテーマ紹介や丸井POP-UPのQR等を検討。自然に利用者が集まる前提にはしない。

## 3. Web MVP（既存の本人報告、今回直接のコード検証なし）

- DISCOVER：1商品ずつイメージイラストを中心に紹介。前後移動可能（現コードの次ボタンは最終から先頭へ循環）。
- DISCOVERY POINT：その商品の特徴を開示。特徴が短い場合は強制的な隠し演出を見直す余地がある。
- COLLECTION／PRODUCT：一覧と詳細。
- WISHLIST：ハート操作で保存・解除。保存はブラウザーのlocalStorage（ログイン・同期なし）。
- スマートフォン優先、深緑・アイボリー基調。ボタンとスワイプの誤操作を避ける。
- 5商品デモMVPは本人が動作確認済みと報告。**2026-11-11に実装repoの index.html を静的確認済み**（実機は未確認）。デモは仮イラスト・仮情報で、外部リンクは**公式購入先ではなく元のInstagram投稿**。正式な商品購入先案内・10候補の正式公開・テーマ管理・POP-UP開催情報／商品別QRは**未実装・未確定**。

## 5. 丸井グループとの連携（**選択済み提案B案、提携未成立**）

**抹茶との出会いを、Webから街へ。**

- DISCOVERY WALL：許諾済みの10商品を写真・紹介文等で展示（全商品を現物展示する意味ではない）。
- DISCOVERY POINT：Web・展示に共通する商品の魅力を紹介。
- MATCHA SELECT：条件が整う**最大3商品を販売候補**とする。具体的商品は未選定。
- WEB CONNECT：商品別QRでWebの商品詳細・保存・次の発見につなぐ構想。
- Web→店舗、店舗→Webの導線を提案。ただし来店数増加・売上増加は未検証。
- 協業成立・掲載許諾・会場・販売主体・仕入れ・温度管理・食品安全・費用は未確定。
- **新しい段階案**：販売の前に許諾済み展示＋QRの小規模実証を検討。10展示＋最大3販売の本命案は維持。詳細はSTEP 10・STEP 12。
- **2026-11-11調査**：一般出店窓口OMEMIEには原則最低7日（一部店舗14日）、営業時間に合わせスタッフ最低2名、固定賃料前払い、商談後最短90日などの条件がある。以前の「3日間・固定費7万円」試算を実出店計画の根拠にしない。好きコン協業への同条件適用は未確認。

## 6. 収益モデル（方向性維持、契約・実績なし）

- **Web：成果報酬型送客を優先検討**。契約が成立し、成果が承認された場合だけ収益。通常の公式購入先リンクは**報酬0円**。未成年者の契約制限は確認し、回避しない。
- **POP-UP：物販を並行検討**。直営／委託／事業者側販売などの販売主体と、売上・費用・在庫責任の配分は未決定。MATCHA ROUTEに全売上が入るとは扱わない。
- 商品順位は報酬額だけで決めない。提携・広告関係を適切に明示する。
- **古い直接販売EC試算は現行の収益予測に使わない。** 正式な事業収益は契約・実測・費用見積もりを基に判断。

**計算の参考（すべて仮定で実績ではない）**
- Web：商品詳細閲覧者3,000人/月、外部遷移率15%、その後の購入率3%、承認率90%、200円/承認 → 2,430円/月（契約時のみ）。月固定費3,000円の仮定なら赤字。
- POP-UP：旧試算の平均1,500円・原価率60%・変動費5%・固定費70,000円という仮定なら134件で損益分岐。ただし**一般出店条件と合致せず、商品構成・必要人員・会場費にも根拠がない**ため、実施計画や黒字化の根拠には使用しない。
