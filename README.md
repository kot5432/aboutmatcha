## 企画概要（決定済み）
- 名称：**MATCHA ROUTE**
- キャッチコピー：**知らない抹茶に、会いに行こう。**
- 初回DROPテーマ：**まだ知らない、抹茶の10のかたち。**
- 価値：珍しい抹茶スイーツとの「発見そのもの」を楽しめること。購入は任意。
- 企画者自身がSNSで知らない抹茶スイーツを見つける楽しさを出発点とする。「買えなくて困っている」という課題は作らない。
- 想定利用者：抹茶スイーツや珍しいスイーツ、新しい食体験に興味を持つ人。具体的な顧客層と需要規模は未確定。

## Web MVP（採用仕様）
- **DISCOVER**：写真中心で1商品ずつ紹介。タップすると「DISCOVERY POINT」の短い見出しと補足を表示。
- **COLLECTION**：一覧型で商品を見る。
- **PRODUCT**：商品詳細。
- **WISHLIST**：明示的なハートボタンで保存・解除。ブラウザーの localStorage に保持。ログイン・決済なし。
- 左スワイプ＝次の商品、右スワイプ＝前の商品。端では循環しない。ボタン操作も可能。保存・詳細・開示ボタンからのスワイプ誤動作を避ける。
- 開示状態は商品間の移動中に保持し、ページ再読み込みでは初期化。
- スマートフォン優先。深緑・アイボリー基調。写真を主役にし、商品番号「01 / 05」は写真外に置く。スワイプ案内の可読性を確保。
- まず5商品のデモ版を改善し、その後10商品構想へ。画像やデモデータを実商品の検証済み情報として扱わない。
- STEP 4-2A（発見ポイント）、4-2B（スワイプと保存）、4-2C（スマホ表示）を改善。STEP 4-3の5項目は企画者から確認完了の報告あり。
- 最新報告コミット：https://github.com/kot5432/matcha/commit/401a4b62dc6e66edd5681bb8b66d05a9060da81d

## 丸井グループとの連携（採用した**提案案**、提携未成立）
**連携案B：抹茶との出会いを、Webから街へ。**
- DISCOVERY WALL：10商品を紹介する展示。
- MATCHA SELECT：うち3商品を販売候補とする。
- WEB CONNECT：QRコードでWebと店舗をつなぐ。
- Webの発見から店舗への来訪、店舗から次のWeb閲覧につなぐ循環を仮説として提案。
- 出店、仕入れ、販売許可、マルイとの協業は**未確定**。

## STEP 5以降の方針（決定済み）
- 応募前のユーザーテストは**必須にしない**。未実施の検証を実績として示さない。
- STEP 5：市場・競合調査。抹茶市場だけでなく、スイーツの発見行動と商業施設のPOP-UPも調査。

- STEP 6：商品候補とマルイ連携の具体化。
- STEP 7：事業モデル・収支計画の精緻化。
- STEP 8：応募資料の作成。応募締切は**2026-12-11**を前提とし、提出前に公式要項を再確認する。
- 追加機能の開発より、事業価値・独自性・実現可能性の説明を優先。
