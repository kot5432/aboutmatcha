## 今回確定した方針
1. MATCHA ROUTEの中心体験は無料の商品発見・DISCOVERY POINT・保存であり、購入を強制しない。
2. 商品ごとに販売情報を区別する：**公式通販の商品ページあり／店舗限定で通販なし／販売情報を確認中**。
3. 確認できた場合に限り公式の適切なリンクを提示する。販売情報が未確認なら購入可能とは表示しない。
4. 保存済み一覧から商品詳細を開けるようにする。
5. MATCHA ROUTEで決済せず、外部の公式販売事業者等へ任意遷移。**公式リンクは成果報酬リンクではなく、送客収入はない**。
