# STEP 51｜商品詳細から「次の抹茶へ」押下時に画像画面へ戻す

更新日：2026-11-12

## 背景
ユーザーが「商品の詳細に行ったとき、次の抹茶へ進むとそのまま次の商品の詳細が表示されるので合っていますか？」と確認。
以前の実装は詳細→次の商品の詳細を直接表示していたが、MATCHA ROUTEの中心である「まず大きな画像を見て、気になったらタップする」という発見体験が省略されてしまう。
ユーザーが「そうしましょう」と仕様変更を承認。

## 採用した動作
1. 商品Aの詳細画面で「次の抹茶を見る →」を押す。
2. 詳細モーダルを閉じ、「一品ずつ見る」に切り替える。
3. 商品Bの大きな画像が表示され、画像ボタンにフォーカスを移す。
4. 利用者が画像をタップしたときに初めてBの詳細を開く。
5. 最後の5商品目の「もう一度めぐる ↺」は1商品目の大きな画像へ戻る。
6. 一覧表示・保存一覧から詳細を開いていた場合も、次へ押下後は同じ発見型の大画像画面を表示。
7. 発見型への移動は smooth scroll を使うが、`prefers-reduced-motion` なら自動移動にする。

## 変更範囲
- `kot5432/matcha/index.html` の商品詳細の `detailNext` のクリック処理とボタン名だけを変更。
- 商品データ5件、画像、購入・店舗案内、固定ID保存、初回ガイド、一覧型、一般のスワイプ操作は変更しない。
- 応募資料v21は変更しない。
