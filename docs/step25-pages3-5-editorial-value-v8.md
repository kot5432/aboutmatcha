## この変更のねらい

「抹茶に特化」「一品ずつ」「保存」という一般的な機能の列挙から、**テーマに沿って商品を選び、紹介順とDISCOVERY POINTを編集することで、異なる種類の発見を連続させる体験**へ、価値の説明を具体化する。

ここでの編集・テーマ運営は事業構想であり、5件のデモMVPに正式なテーマ管理や10件の正式商品が実装済みとは言わない。利用者による競合比較・優位性検証は未実施。

## P3変更

- 見出し：「探す前に、思いがけない抹茶と出会う。」
- 第一対象：「抹茶スイーツが好きで、次に食べたいものはまだ決まっていない人」を明確化。
- 中央の体験カード：「テーマで選んだ／一品に出会う」および「写真から惹かれ、特徴を知り、気になるものを保存する」。
- 下部注記：SNS・通販にも発見はあることを明示し、本企画は「**テーマに沿う選定・紹介順・発見ポイント**」を編集する体験の提案とする。競合にない唯一の機能と断定しない。

## P5変更

- 見出し：「一つのテーマから、3つの違う『食べてみたい』。」
- 初回テーマ案「まだ知らない、抹茶の10のかたち。」は構想であり、現在のWebで10商品を公開済みとはしない。
- シェ・アガタのテリーヌ＝素材と製法、きよ泉の最中＝食べる前に自分で仕上げる体験、茶町KINZABUROの富士山パウンド＝断面の形という、**異なる発見ポイントを順番に提示**。
- 下帯に「編集の工夫：素材のこだわり → 自分で仕上げる体験 → 切って驚く見た目」を追加。単なる商品カードの並びではなく「編集した出会いの流れ」を説明。
- 商品写真の利用許諾は未取得。既存の自作イメージ図を維持し、掲載・販売候補の注記を残す。
