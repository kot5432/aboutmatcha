# STEP 9-6｜Web×店舗の体験設計と応募回答改訂

日付：2026-11-11

## 方針
Webは常設の発見サービス。POP-UPは丸井との連携が実現した場合の拡張。店舗のQRは単なる商品説明ではなく、詳細・保存・次の発見につなぐ。

## Webと店舗の役割
- Web：写真から商品を一つずつ発見、DISCOVERY POINTを開く、保存、購入先を確認。
- 店舗：10商品の展示（展示方法・画像許諾は要確認）、3商品を販売候補として実物確認と任意購入。
- Web→店舗：発見・保存→開催情報を確認→展示を見る／購入検討。
- 店舗→Web：展示→商品別QR→特徴・作り手の情報→保存→DISCOVERへ戻り次の商品を発見。
- 店舗のQRは特定の商品詳細へ誘導する。商品別QR、開催情報、関連導線は追加実装の構想であり現MVP実装済みとは区別。
- 展示対象の商品名や写真の使用、商品供給、丸井との協業は未許諾・未契約。実物展示を全10商品で約束しない。

## ③ 事業アイデア概要
私が提案する「MATCHA ROUTE」は、抹茶スイーツとの出会いを実際の体験につなぐWebサービスです。写真や意外な特徴から商品を発見し、保存や購入先の確認ができます。

さらに丸井グループの店舗で、10商品を紹介する発見体験型POP-UPを構想。商品の特徴を伝える「DISCOVERY POINT」とQRコードを通じて、Webと店舗を行き来できる体験をつくります。3商品を販売候補とし、購入しなくても楽しめる場を目指します。

Webでの成果報酬型送客とPOP-UP販売による収益化を検討しています。

## ④ 同じ好きを持つ人の共感
抹茶好きの人なら、知らない抹茶スイーツを見つけたとき、「食べてみたい！」とワクワクすることがあると思います。私自身も、そんな瞬間が大好きです。

MATCHA ROUTEでは、商品を一つずつ発見し、意外な特徴を知り、気になったものを保存できます。さらに丸井グループのPOP-UPでは、Webで興味を持った商品の実物に出会うことも目指します。

「知らなかった！」という発見が「いつか食べたい」「実際に見てみたい」という楽しみにつながり、また新しい商品を探したくなる。そんな体験が共感を呼ぶと考えています。

## ⑤ 解決する課題と意義
解決したいのは、魅力的な抹茶スイーツがあっても、その存在や作り手のこだわりを知らず、出会う機会を逃してしまうことです。また、商品に興味を持っても、実際に楽しむきっかけがないまま終わる場合もあると考えています。

MATCHA ROUTEでは、Webでの発見・保存・購入先案内と、丸井グループのPOP-UPでの実物体験をつなぎます。利用者には新しい楽しみを、作り手には商品を知ってもらう機会を届けます。

一つの出会いから新しい「好き」が生まれ、作り手の魅力がより多くの人へ伝わることに意義があると考えています。

## 残る論点
- QRからの商品詳細、保存、DISCOVERへの戻り導線の最小実装とデモ
- 10商品展示の画像等の権利と3商品の販売可能性
- 店舗との連携の実現条件
- 実際のユーザー需要、Web→店舗／店舗→Webの効果は未検証
