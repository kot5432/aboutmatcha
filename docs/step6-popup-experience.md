# STEP 6-2｜POP-UP体験設計（提案用標準プラン）

更新日：2026-11-10  
状態：**提案案として具体化**。会場・協業・商品販売・費用は未確定。

## 目的とコンセプト
**抹茶との出会いを、Webから街へ。**

単なる物販催事ではなく、知らなかった抹茶スイーツの個性を発見する体験をつくる。購入しない人も楽しめる設計とする。

体験導線：**発見 → 興味 → 実物 → 任意の購入 → 次の発見**。

## 基本構成（既決方針を具体化）
- **DISCOVERY WALL：10商品**。写真・商品名・短い問い／DISCOVERY POINT・作り手・QR。写真の権利処理ができない商品は掲載しない。展示物や商品の現物を全点用意する前提にはしない。
- **MATCHA SELECT：3商品を販売候補**。役割は①気軽に購入②手土産・ギフト③発見の目玉。実際の販売3商品は未決定で、仕入れ可否・温度管理・許可で最終選定。
- **WEB CONNECT：QRからWebへ**。商品詳細、他の発見、保存へ誘導。QR先は公式の安全なURLとし、読み取りを強制しない。

## 来場者の体験（想定3〜7分、目標値ではなく設計上の目安）
1. **入口：ひと目で伝える**。「まだ知らない、抹茶の10のかたち。」のタイトルと代表的な写真。価格・購入を前面に押し出さない。
2. **発見：壁面を自由に見る**。各商品の問いを先に見せ、補足説明で「意外性」を伝える。順番は固定しない。人が多い場合も通路を塞がない。
3. **興味：気になる商品を選ぶ**。10商品のうち気になるものを見つける。カードごとのQRでWebの該当商品へ進める構想。QRが使えない人向けに商品名とURL等を併記。
4. **実物：販売可能な3商品を確認**。現物・包装・価格・アレルゲン等、販売に必要な情報を分かりやすく表示。販売できない7商品は展示紹介であり、購入可能と誤認させない。
5. **購入：希望者のみ**。販売・決済・受け渡しは契約先・施設ルールに沿って運営。試食は初期案に含めない。
6. **次の発見：Webへ**。購入の有無にかかわらず他の商品を閲覧・保存できる。紙の持ち帰り案内は任意の代替策。

## 会場レイアウト（概念図・寸法未確定）
- 通路側：タイトル・キービジュアル。通行を妨げない。
- 壁面または展示面：DISCOVERY WALL（10商品）。入口から閲覧できる配置。
- スタッフが見守れる販売台：MATCHA SELECT（3商品）。在庫は温度・衛生条件に合わせ別管理。
- 出口／販売台付近：WEB CONNECTの案内。
- 車椅子・ベビーカー利用者や混雑時の通行を想定し、必要な有効幅は会場規定で確定。展示・会計待機列が通路へはみ出さないことを優先。

## 展示情報のテンプレート
各商品に以下を掲載：
- 商品名・ブランド／作り手
- 写真（使用許諾を確認）
- 興味を引く短い問い（事実誤認を招かない）
- DISCOVERY POINT：公式情報で確認できる特徴
- 販売状態：「この会場で販売」「紹介のみ」を明記
- QRと文字URL（該当商品ページへの導線）
- 販売品は価格、食品表示・アレルゲン等の必要事項を別途掲示

## 最小限の運営構成（仮置き）
- 展示パネル／商品説明カード10点、QR表示
- 販売台、価格表示、必要な決済・レジ機器
- 商品別の適切な保管設備（冷凍・冷蔵品は実施条件次第）
- スタッフによる案内・会計・補充・安全確認
- 混雑時は閲覧を止めずに販売待機列を誘導
- 仕入れ、食品営業許可・届出、表示、保険、施設規則、廃棄方法は実施主体と商品構成が決まってから確認

**初回の簡易実証では、実演調理・試食・複雑な冷凍提供を必須にしない。** 目玉商品は展示中心とする案も残す。

## 仮説と検証指標（実績ではない）
- 発見した商品への関心：どの商品に注目したか（任意の聞き取り等）
- Web接続：QR読み取り／商品ページ閲覧（プライバシー配慮・計測実装がある場合のみ）
- 物販：商品別販売数・売上・廃棄・在庫
- 運営：混雑、補充負荷、保管上の問題
- 展示と販売の関係：展示だけ見た来場者も含めて体験を評価

数値目標・実施日・会場面積・人員・予算は未決定。既存の3日間・固定費7万円等は**試算上の仮定**であり、このレイアウトの見積もりではない。

## リスクと対応
| リスク | 対応案 |
|---|---|
| 商品掲載・写真の権利 | 事前許諾。許諾不可なら差し替え |
| 販売契約・仕入れ不成立 | 候補の代替品を用意。販売品を確定扱いしない |
| 冷蔵・冷凍・衛生管理 | 条件を満たせる商品のみ販売 |
| 混雑・動線 | 展示と会計の待機位置を分ける |
| 購入可能と誤認 | 「販売」「紹介のみ」を明示 |
| QR利用困難 | 商品名とアクセス先を文字でも案内 |
