# STEP 9-5｜発見体験型POP-UP（B案）と応募回答の改訂

作成日：2026-11-11

## 決定事項
POP-UPは**B案「発見体験型」**を採用する。Webを常設の事業の中心とし、丸井グループの店舗との連携によってリアルの発見体験へ拡張する。丸井との連携は提案段階であり、合意済みではない。

### POP-UPの4要素
1. **DISCOVERY WALL**：10種類の抹茶スイーツを紹介する展示。購入しなくても楽しめる。
2. **DISCOVERY POINT**：各商品の意外な特徴や作り手のこだわりを、展示とWebで紹介する。
3. **MATCHA SELECT**：役割の異なる3商品を販売候補にする。具体的な商品は未決定。
4. **WEB CONNECT**：商品別QRからWebの詳細・保存へ案内する。

### 双方向の導線
- **Web→店舗**：商品を発見→保存→POP-UP情報を確認→会場で実物を見る／購入を検討。
- **店舗→Web**：展示を見る→QRを読み取る→DISCOVERY POINTや詳細を見る→保存・後日閲覧。
- POP-UPに行かなくてもWebで発見・保存・購入先確認ができる。
- POP-UP情報表示と商品別QRの遷移先は追加実装の構想。現MVPの実装済み機能と区別する。

### 関係者への期待価値（未実証）
- 利用者：Webで知った商品を実物で確かめる／店舗で知った商品を後から見返す。
- 作り手：商品の特徴やこだわりを伝える新しい接点。
- 丸井グループ：来店動機と来店後も続くWeb上の接点。
- MATCHA ROUTE：Web成果報酬型送客とPOP-UP販売の両面を検討。いずれも契約・実績はない。

## 応募フォーム設問③｜事業概要（目安200字・最大400字）
私が提案する「MATCHA ROUTE」は、知らない抹茶スイーツとの出会いから実際の体験までをつなぐWebサービスです。写真や意外な特徴から商品を発見し、保存や購入先の確認ができます。

さらに丸井グループの店舗で、10商品を紹介する発見体験型POP-UPを構想。商品の意外な特徴を伝える「DISCOVERY POINT」とQRコードを使い、Webと店舗を双方向につなぎます。3商品を販売候補とし、購入しなくても楽しめる場を目指します。

Webでの成果報酬型送客とPOP-UP販売を収益源として検討しています。

## 応募フォーム設問④｜共感（目安200字・最大400字）
抹茶好きの人なら、知らない抹茶スイーツを見つけたとき、「食べてみたい！」とワクワクすることがあると思います。私自身も、そんな瞬間が大好きです。

MATCHA ROUTEでは、写真から商品に出会い、意外な特徴を知り、気になったものを保存できます。さらに丸井グループのPOP-UPでは、Webで興味を持った商品の実物に出会える体験を目指します。

「知らなかった！」という発見が「いつか食べたい」「実際に見てみたい」という楽しみにつながることが、同じ抹茶好きの共感を呼ぶと考えています。

## 応募フォーム設問⑤｜課題と意義（目安200字・最大400字）
解決したいのは、魅力的な抹茶スイーツがあっても、その存在や作り手のこだわりを知らず、出会う機会を逃してしまうことです。また、気になる商品を見つけても、実際に楽しむきっかけがないまま終わる場合もあると考えています。

MATCHA ROUTEでは、Webでの発見・保存・購入先案内と、丸井グループのPOP-UPでの実物体験をつなぎます。利用者には新しい楽しみを、作り手には商品を知ってもらう機会を届けます。

人の「好き」が広がり、作り手の魅力が新しい人へ届く接点を増やすことに意義があると考えています。
