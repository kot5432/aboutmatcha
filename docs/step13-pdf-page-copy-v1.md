## 編集上の共通ルール

1. **結論のある見出し／要点2〜3個／根拠となる図か画像**を一組にする。写真だけのページや説明のない矢印図にしない。
2. 正式導入時の写真中心の体験と、**現在のイメージイラスト5商品MVP**を明確に分ける。
3. P4で示す実際の試作品は**参照元Instagramリンク**。公式購入先の案内・テーマ管理・POP-UP商品別QRは今後の機能。
4. 掲載予定の「10商品」や販売候補「最大3商品」は**構想**であり、許諾・仕入・会場の確約はない。
5. 「SNSでは発見できない」「初の抹茶発見サイト」などは主張しない。抹茶特化の競合は存在する。
6. P8で根拠のない売上・黒字化予測を掲げない。一般出店OMP/OMEMIEの条件から従来の3日間・7万円試算は実行根拠に使えない。
7. 出典・条件・実装状態を端的に示す。小さすぎる注記は禁止。
8. 商品写真・店名ロゴは権利を確認した素材だけ使う。確認前の作業版では自作の抽象アイコン／図形・テキストカードで代替。実物の写真を無断に使用しない。
9. 1ページに主たるメッセージ1つ。P6は体験・協業、P7は三者の便益、P8は取引・費用を担当。
10. 「開発済みとの報告／ソース静的確認」「今後の計画」「連携提案」「未検証」の状態が見分けられるよう表記を統一する。

## P1｜表紙：何をする事業か

**大見出し：知らない抹茶に、会いに行こう。**
**名称：MATCHA ROUTE**

**掲載本文（コピー可）：**
「MATCHA ROUTEは、まだ知らない抹茶スイーツのおいしさや魅力を、テーマごとに発見するWebサービスです。丸井グループとの連携で、その発見を店舗での体験へと広げる事業を提案します。」

補助ラベル：「抹茶スイーツの発見 × Web × 店舗体験」
下部：「Web試作品を開発中／店舗連携は提案段階」

**レイアウト：** 左55%にコピーと1〜2行説明、右45%に権利確認済みの商品写真（未許諾なら抹茶を想起させる自作グラフィック）。背景は生成り。ロゴより「事業内容」が早く読めるようにする。
**読み手の疑問：** 何を提供する事業？
**使う素材：** ブランド名、コピー／写真は権利確認後。

抹茶があまり好きではない友達にお菓子を渡したとき、『おいしかった』と言ってもらえました。自分の好きなものの魅力が誰かに伝わる喜びを、もっと多くの人に届けたい。その思いがMATCHA ROUTEの出発点です。」

**図：** 「抹茶アイスが特別だった」→「友達の『おいしかった』」→「発見の場をつくりたい」の3つの短いカード。中央を少し大きく。友達の写真・証言画像は不要。
**根拠：** 応募者本人が申告したエピソード。
**注意：** 友達が抹茶好きになったと書かない。

## P7｜誰の価値に変わるか

**掲載本文：**

**価値図（各者の期待価値と、後に確かめることをセットで）：**

- 作り手：魅力が届く新しい接点 → 「紹介ページや参照元への関心」

**図：** 中央MATCHA ROUTE、周囲3者を矢印でつなぐ。各者のカードに一行の「期待する価値」と一行の「検証すること」を置く。

## P8｜収益と成立条件（特に重要）

**大見出し：無料の発見体験を、継続できる事業へ。**

**掲載本文：**
「Webでは無料で発見・保存できます。今後、公式購入先への任意送客と、契約・成果承認が成立した場合の成果報酬を検討します。POP-UPでは、一部商品の物販を候補とし、誰が販売し、費用を負担し、利益を受け取るかを協議します。」

**図：左右の収益フロー**
- Web：利用者（無料で発見）→公式購入先（今後整備）→購入・成果承認→**契約時のみMATCHA ROUTEに報酬**
- POP-UP：展示と任意購入→**販売主体（未定）に売上**→仕入れ・会場・人件費等→**MATCHA ROUTEへの取り分は契約次第**
- 下部の確認条件：掲載権利／契約主体・年齢条件／商品供給／食品管理／実費用・スタッフ

**明確な注記：** 現在、成果報酬契約・店舗協業・販売実績なし。公式リンクに報酬契約がなければ収益は0円。過去の「3日間・固定費7万円」モデルは公式一般出店条件・実費見積もりとの整合が取れないので掲載しない。
**注意：** ビジネスコンテストだからと利益額を捏造しない。数字は実見積後に追加。スポンサー掲載料等を新しい決定済み収益源にしない。

## 版面とデザイン（制作担当向け）

- 第一候補は16:9横。文字の多いP8を除き、1ページの主な本文は80〜140字程度の目安。P2はストーリーとして長くてもよい。最終的には実画面・図と読める文字サイズを優先し、無理に制限しない。
- 基本色：深緑 #214B38、抹茶 #7C9862、生成り #F7F4EA、本文 #252B27。
- タイトル30〜36pt、本文18〜22pt、注記原則14pt以上を目安。縮小表示でも注記が読めない場合は文章を整理し、ページを増やす判断も可能。
- P1は大きな見出し、P2は体験の流れ、P3は価値の前後、P4は実画面、P5は商品例、P6は会場とWeb、P7は関係者、P8は収益フロー、P9はロードマップ。
- アイコン・写真が文字の繰り返しにならないよう使い分ける。図中ラベルが短すぎて意味不明にならないよう一行の説明を併記。
- 画像の出典／ライセンス／掲載承諾と、文章の根拠URLを制作用のアセット台帳へ記録。提出版で他社商品を推薦・広告していると誤認させないため「紹介候補（未契約）」を必要箇所に示す。
- 正式応募条件（PDF形式、容量、ページ数、応募資格・年齢）を提出前に公式フォームで再確認。

## 変更理由の要約（STEP 10からの差分）

- P4：**MVPのInstagram投稿リンク**と未実装の公式購入先を明示的に分離。
- P5：体験の伝わる公式情報由来の具体的3商品を提示。「金平糖」は2026年一次情報未確認のため、資料の主役からいったん外し、断面が説明しやすい富士山パウンドを採用候補に。
- P6：一般出店OMEMIEの運営条件を踏まえ、**展示実証→条件付き物販**の段階化を明確化。
- P7：3者への価値と測定項目を紐づけ、未実証効果を断定しない。
- P8：販売主体と収益帰属を分離し、成果報酬の**契約なし=0円**を明示。根拠なき利益予測は掲載しない。
- P9：短い夢だけで終わらず、丸井に協議してほしい具体事項を記載。
