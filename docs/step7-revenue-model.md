# STEP 6-4〜STEP 7｜三者の価値と二本立ての収益方針

更新日：2026-11-10

## 決定事項
- **STEP 6-4：B案（POP-UP物販とWeb送客収益を並行検討）を採用。**
- MATCHA ROUTEの中心は無料の発見型Web。購入を強制せず、気になる商品の公式販売先への遷移を任意で提供する。
- 高専生としてのWeb開発力を活かし、Web自体にも収益可能性を持たせる方向を重視。
- 丸井グループとのPOP-UPは実物との出会いと物販の実証機会。事業のすべてを催事に依存させない。
- **成果報酬型の送客をWebの初期優先検討モデルとする提案**。具体的なASP・提携先・報酬率は未決定。契約のない公式リンクからの収益はゼロ。

## 提供価値と役割分担（契約未成立）
| 関係者 | 期待する価値 | 想定する役割 |
|---|---|---|
| 利用者 | 未知の抹茶スイーツの発見・保存、任意の購入 | 閲覧・任意の行動 |
| MATCHA ROUTE | Web送客報酬とPOP-UP販売粗利の可能性 | Web開発・運用、商品紹介の編集、提携交渉、計測と収支管理 |
| 商品事業者 | 新規認知・販売機会 | 正確な商品情報・写真使用許諾、商品供給、ECでの注文処理（提携方式による） |
| 丸井グループ | 来店動機・顧客接点の拡大可能性 | 会場・館内告知・運営条件の協議（提供は未合意） |
| POP-UPの販売主体（未定） | 販売収益 | 仕入れ、食品表示、衛生管理、決済、返品、在庫・売上処理等を契約で確定 |

## 収益経路1：Web送客（優先検討）
発見 → 詳細 → 明示した外部ショップリンク → 提携先で購入 → 条件を満たした成果のみ報酬。
- ASP案件の有無、提携可能ブランド、成果条件・否認・返品・支払条件を確認する。
- 利用者に広告・アフィリエイトの関係を適切に明示する。
- 紹介の公平性を保つため、報酬の有無だけで商品順位を決めない。
- Cookie等の計測、個人情報、利用規約、プラットフォーム規約を実装前に確認する。
- 成果計測は自社側だけで完結しない場合がある。
- 未成年の企画者が契約主体となれるかは各サービス・契約条件を確認する。

## 収益経路2：POP-UP物販（並行検討）
展示10商品、販売候補3商品。物販の利益は売上から仕入原価・決済手数料・廃棄・出店料・人件費・輸送・保管等を差し引く。仕入販売／委託／施設側販売などの方式は未決定。丸井・商品事業者との費用負担と売上配分は要交渉。

## STEP 7：収支検討のための仮定例（**実績・予測ではない**）
Web送客例：月間商品詳細閲覧者3,000人 × 外部サイト遷移率15% × 遷移後購入率3% × 承認成果1件あたり200円 ≒ **月2,700円（経費控除前）**。端数処理で実際の件数は変わる。提携契約がなければ0円。

既存のPOP-UP例：3日間、固定費70,000円、客単価1,500円、原価率60%、その他変動費率5% → 限界利益525円／購入、損益分岐約134購入。**人件費・輸送・設備等が固定費仮定に含まれるか未検証。**

### STEP 7で調べること
1. 候補10商品に対応する合法的な成果報酬提携の有無と条件
2. 送客率・購入率の根拠、想定流入源と集客コスト
3. Web運営費（ドメイン、ホスティング、保守、商品編集、計測）
4. POP-UPの販売主体、仕入・出店・保管・人員・決済・廃棄費用
5. 事業全体の月次・イベント別収支と赤字時の撤退・改善条件
