# MATCHA ROUTE｜本人の原体験と事業動機（2026-11-10）

## 本人が語った経験（要約、未創作）
- 小学生の頃、甘いものやお菓子・アイスはあまり好きではなかったが、抹茶アイスだけはとてもおいしく感じ、よく食べた。
- それ以来抹茶が好きで、濃いほどおいしく感じる。抹茶を食べると幸福感があり、抹茶商品を見かけると手に取り、買うことが多い。
- 抹茶のお菓子を友達へのお土産として渡した。友達はもともと抹茶があまり好きではなかったが、そのお菓子は「おいしかった」と言ってくれた。
- 自分の好きなものを他の人がおいしいと感じてくれたことがうれしかった。抹茶にあまり親しみのない人にも魅力を知ってほしいと考え、自分にできることを探した。

## 事業ストーリーへの接続
自分が抹茶を好きになった経験 → 好きな抹茶を友達に紹介し、喜びを感じた経験 → より多くの人に抹茶の魅力に出会うきっかけを届けたい → MATCHA ROUTE（Webでの発見、将来の店舗での実物体験）。

## 表現上の注意
- 友達が「おいしかった」と言ったことは事実として扱う。
- 友達が「抹茶を好きになった」とは確認されていないため書かない。
- 「誰でも一度食べれば抹茶を好きになる」と一般化しない。
- 「好きにさせる」より「魅力に出会うきっかけをつくる」。
- もともとの中核価値「購入しなくても発見が楽しい」は維持し、食べてみたい人には任意の購入導線を提供する。
- 抹茶好きの探索と、抹茶に親しみのない人への紹介の両方を対象候補として扱い、主対象の優先順位は別途検討。

## 応募用ドラフト
私は小学生の頃から抹茶が大好きです。当時は甘いものやお菓子があまり好きではなく、アイスもそれほど食べられませんでしたが、抹茶アイスだけは特別においしく感じ、よく食べていました。今でも濃い抹茶が大好きで、抹茶の商品を見つけるとつい手に取ってしまいます。

以前、抹茶があまり好きではない友達に抹茶のお菓子をお土産として渡したことがあります。その友達が「おいしかった」と言ってくれたとき、自分の好きなものの魅力が誰かに伝わることが、とてもうれしいと感じました。抹茶にあまり親しみのない人でも、出会う商品によって新しい魅力を感じられるのではないか。大好きな抹茶の魅力をもっと多くの人に届けたい。そんな思いから、MATCHA ROUTEを考えました。
