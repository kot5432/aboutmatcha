## 1. 商品を紹介する前に満たすべきゲート

| ゲート | 最小限の必要条件 | クリア前の扱い |
|---|---|---|
| A 実在・表記 | 作り手の一次サイト等で現在の商品名・特徴・入手形態が確認できる | 候補・調査中 |
| B テキストの正確性 | 特徴が公式情報と整合し、確認日とURLを残せる | 未校正の紹介文として保留 |
| C 画像権利 | 利用する画像の作成者・利用許諾・利用範囲・表示条件が確認できる | 公式商品画像は転用しない |
| D 公開状態 | 通販可・店舗限定・時期限定・販売終了・未確認を区別する | 購入可能と誤認させない |
| E POP-UP展示 | ブランド名・写真・展示文章等の許諾と施設条件が成立 | 予定展示商品と断定しない |
| F POP-UP物販 | 商品供給・販売主体・実仕入・食品管理・決済と責任分担が成立 | 販売予定商品と断定しない |

**A/BだけでC/E/Fを満たしたことにはならない。** 公開に向けた商品差し替えは可能。候補10件を守るために不正確な内容を無理に公開しない。

## 4. 応募添付PDFで使う候補例

**写真が許諾されるまで、製品画像の無断利用はしない。** 少なくとも特徴が異なる次の3例なら、MATCHA ROUTEの編集による発見を説明しやすい。

- シェ・アガタ：素材のシンプルさ・濃厚な抹茶という**味わいの方向**
- きよ泉：自分で仕上げる最中という**食べるプロセス**
- 茶町KINZABURO 富士山パウンド：断面の富士山という**見た目**

前2品はセット構成や価格が異なるので、POP-UP販売を確定扱いにしない。さらに一般的な抹茶プリンなども別テーマでは扱う方針を併記して「珍品専用サイト」に見せない。

## 5. 企画者が最小限確認すること（まだ問い合わせは行っていない）

- 商品紹介：公式名称／商品自体の現在の販売状態／商品の特徴の事実確認／ブランド紹介のクレジット方針／写真・ロゴの使用許諾。
- 会場展示：紙パネル等での名称・画像使用、QRからWebへ誘導することの可否。
- 物販：販売主体／卸・委託条件／価格／最小ロット／納期／保存温度／賞味期限／食品表示／返品・廃棄責任。
- 調査完了前は候補のまま扱う。事業者への正式な提携依頼や販売条件の交渉をこちらで行った事実はない。

## 6. 収益モデルへの反映

公開小売価格450円（冷凍カヌレ）、2,700円（京番茶皮・抹茶あんの最中）、4,413円（テリーヌハーフ）、7,708円（通常テリーヌ）など、**種類・単位・温度帯ごとに価格が大きく違う**。

- 以前の一律平均客単価1,500円は、候補商品の組み合わせに基づく推計ではない。
- 販売品の3商品選定は、見た目の面白さよりも卸の可否・保管・販売場所・数量・権利・利益配分の実条件を優先する。
- 作り手・丸井・MATCHA ROUTEの間で誰が販売主体か未確定。各社に売上と利益がどう分配されるかは未決定。
