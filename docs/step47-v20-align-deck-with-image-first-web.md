# STEP 47｜v20：応募資料のWeb説明を画像中心の新UIへ整合

更新日：2026-11-12

## 目的
Webデモの操作が「初回案内 → 大きな商品画像 → タップでDISCOVERY POINT・NEXT CONNECTION → 保存／次の商品 → 入手方法」に更新されたため、応募資料v19のP4に残った旧UIのキャプチャ・説明を更新する。本人の希望どおり、事業のストーリー・P2個人写真・P5商品イラスト・丸井連携・収益説明は維持する。

## 今回の変更
- 最新元資料：`MATCHA_ROUTE_応募資料_v19_章ラベル統一.pptx`
- 新資料：`MATCHA_ROUTE_応募資料_v20_新Web体験画像整合.pptx` と同名PDF（全9ページ）。
- **P4だけ**画像と文字を差し替えた：
  - 左：画像を大きく見せる商品発見カード。
  - 右上：タップ後に開くDISCOVERY POINTとNEXT CONNECTION。
  - 右中：保存ボタンと入手方法。
  - 下：従来どおりWeb URLとQRコード。
- v19の「現在の5商品デモの実画面」という説明は使わず、`現在のWebに合わせた発見体験を、画面イメージで紹介します。`に変更。
- 注記は**「実装内容をもとに再現した新UI画面例」**と明記した。公開サイトの本物のキャプチャと混同しないため。
- 参考UIは、GitHubの最新Web実装の構成・実際の商品紹介文に合わせ、v19スライドに埋め込まれた元Webと同じ抹茶バスクチーズのイメージイラストから**ローカルで描画した再現画像**を使用。新しい商品写真を生成したわけではない。

## 検査
- PPTXからPDFへ変換し、9ページあることを確認。
- v19とv20のPDF抽出テキストを比較し、**P4以外の8ページが完全一致**。
- 4ページの画像・本文がはみ出さず、全ページの文字ブロックがページ内。
- P4の外部リンク2件は両方とも `https://matcha-alpha-pearl.vercel.app/` のまま。
- 商品の出典・イラスト表記・購入導線の実装状況が誇張されないよう、「再現したUI画面例」「一部試作中」と明記。

## Webの品質確認の範囲
- 既存のSTEP 44の保存データ移行テスト4ケースとSTEP 45/46のコード構文・HTML要素整合検査は実施済み。
- このターンでは公開Vercelサイトのページ取得を試みたが、公開ページが取得できず、**本番サイトの操作・狭幅の実機検証は行っていない**。
