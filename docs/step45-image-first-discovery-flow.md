# STEP 45｜画像主役の発見体験への改修

更新日：2026-11-12
状態：**GitHubのindex.htmlへ実装済み。静的検査・JavaScript構文チェック済み。実ブラウザー／公開Vercel反映／スマートフォン表示の最終確認は未実施。**

## 変更の背景
利用者から「操作性があまり面白くない。最初に使い方をポップアップで説明し、その後は大きな画像を表示してタップすると詳細を見られる構成がよい」とフィードバックがあった。

目標：文字を読み始めるUIより、**一品を見て気になる→タップして発見→保存して次へ**という視覚中心の体験にする。大きなアニメーションや複雑なページ遷移を増やさない。

## 実装内容
Webコード：`kot5432/matcha/index.html`

### 1. 初回ガイド
- 初回にモーダルを表示する。3ステップ「写真を見る→タップして発見ポイント→♡で保存」を簡単に説明。
- 「次回から表示しない」（初期オン）。開始時、選択されていれば `localStorage.matchaIntroSeenV1` に保存。未選択なら次回も表示。
- メイン画面の「使い方 ?」からガイドを再表示できる。
- 「抹茶をめぐる →」ボタンで終了し画像にフォーカス。Escでも閉じられる。

### 2. 大きな商品画像を主役に
- 従来の左右2カラムの情報カードから、**商品画像が大きい縦型カード**に変更。
- 画像上には「＋ タップして、魅力を発見」、画像下は商品名・店舗名・保存のみ。
- 1/5ページ表示、ドットナビ、前へ／次へボタン、左右スワイプは維持。
- 押す場所が明確な実ボタン（キーボードで操作可能）として画像を実装。
- スワイプ判定は画像ボタン上のタッチも受け付け、移動操作直後の意図しないタップ開示を抑える。

### 3. 画像タップ→発見詳細
- 既存の詳細パネルを再利用して、**大きな商品イラスト→DISCOVERY POINT→NEXT CONNECTION→保存／次の抹茶→入手方法→参照元Instagram**を順に表示。
- 保存は詳細を閉じず、その場で状態を更新。
- 詳細内の「次の抹茶へ」で同じパネル内の次の商品を表示。
- 商品詳細は従来どおり一覧型・保存済み一覧からも開ける。
- 公式通販・店舗限定・確認中の区別と既存リンクは保持。購入を強制しない。

### 4. レイアウト・操作への配慮
- 720px以下・390px以下の画面に対して画像・文字・ナビのサイズを調整。
- `prefers-reduced-motion` でズームアニメーションを停止。
- ガイドにラベルと説明を付け、モーダルのボタンにフォーカスを当てる。
- Webデモの注意書き、5商品・既存の保存ID (`matchaSavedV2`) を維持。

## 変更しないもの
- 5商品の名前・紹介文・画像・NEXT CONNECTION、商品順。
- 入手方法の区別・正式な通販リンク・参照元Instagramリンク。
- 固定商品IDで保存する形式と旧保存データの移行。
- Webで決済しない方針、応募資料v19の内容・構成。
