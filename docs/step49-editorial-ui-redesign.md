「本当にあるようなアプリにしたい」「左上の『まだ知らない、抹茶のかたち。』などはAIコーディングを彷彿とさせる」「ほかのWebサイトやアプリを参考にUIを変更したい」。

狙い：抽象的なキャッチコピーや装飾的な英語表現を減らす。既に改善された「大画像→タップで詳細→保存・次へ」という操作感を維持し、**日常的に使う日本語の発見メディア**へ寄せる。

参考は設計上の分析。これらのサイトのロゴ、画像、文章、デザインの複製は行わない。

## 具体的に変更したこと
対象：`kot5432/matcha/index.html`

### 1. ヘッダー・見出し
- 削除：「FIELD NOTES / DROP 01」「A LITTLE JOURNEY THROUGH MATCHA」「OSAKA / KYOTO · 5 DISCOVERIES」「まだ知らない、抹茶のかたち。」
- 新しく「MATCHA ROUTE／抹茶スイーツの発見サイト」とし、見出しは **「抹茶スイーツを見つける」** に変更。
- 「5つの抹茶スイーツを紹介」「気になる一品を見つけたら、あとで見返せるように保存できます。」と、機能が分かる具体的な日本語に変更。

### 2. ナビゲーションと操作
- 「発見型／一覧型」→ **「一品ずつ見る／一覧で見る」**。
- 「♡ 食べてみたい」上部ボタン→ **「♡ 保存した商品」**。商品カードの♡保存は維持。
- 「使い方 ?」→「使い方」、画像CTA→「詳しく見る」。
- 表示方法のグループに `aria-pressed` を追加し、選択中の状態を更新。

### 3. 視覚表現
- UIの操作ラベル・本文に読みやすい **Noto Sans JP** を採用。商品タイトルには **Noto Serif JP** を残して食品メディアらしい編集感を保持。
- ヘッダーを暗緑から淡色へ変更し、用紙のような暖色系背景、控えめな緑の線と影でまとまりを作った。
- 商品画像の大きさ、画像タップで詳細が開く操作、次へのスワイプや約0.3秒の演出は変更していない。
- 商品の小カテゴリーも「抹茶 × チーズ」等、意味が伝わる日本語中心の表記にした。
- 詳細の章名を「発見ポイント（DISCOVERY POINT）」「次の一品へ（NEXT CONNECTION）」と日本語を主に配置し、コンテスト資料で使用する固有表現は小さく残した。

### 4. 信頼性と運営情報
- フッターに **「このサイトについて」** を追加。説明ダイアログで「何ができるか」「掲載情報とイメージイラスト」「ブラウザー内保存・端末間同期なし・サイト内決済なし」を説明。
- Webデモであることを隠して実在の運営法人やユーザー実績を装わない。
- 商品5件、参照元Instagram5件、公式通販商品リンク、西条園オペラ・店舗限定マールブランシュの入手情報を維持。
- 詳細ダイアログを閉じる際は、可能なら元の操作位置へキーボードフォーカスを戻す。
