# STEP 50｜商品詳細画面の情報優先順位を改善

更新日：2026-11-12
対象：`kot5432/matcha/index.html`

## ユーザーの要望
「商品の詳細の部分をもう少し見直してください。配置など良いかと思います。」

元の基本配置と画像をタップして詳細を開く体験は維持。細部の見やすさと保存時の使いやすさを改善した。

## 見直した問題
- 元の詳細パネルは、発見型メイン画面で見た大きな商品イメージ画像を再度縦260px程度表示していた。スマートフォンではDISCOVERY POINTが初期表示から遠くなる。
- 「次の一品へ」は最終5番目では商品紹介でなく全体の振り返りなので、表示ラベルを区別する必要がある。
- 詳細パネルで♡を押したとき全HTMLを再生成していたため、スクロール位置・操作フォーカスが不用意に変化するおそれがあった。
- 公式商品の案内・元Instagramリンクが普通の文章に埋もれやすく、リンクと「販売できる」という断定は区別する必要がある。

## 実装
- 商品詳細先頭を **小さなイメージ画像＋商品名・店舗名・商品番号**の横並びに変更。小画面では画像92px、さらに狭い幅では78px。画像は「イメージ」と明記。
- 内容は発見ポイント→次の一品→保存と次へ→入手方法→紹介元リンクの順序を維持。CSSで段落間の余白・文字サイズを調整。
- 5番目のみ「5つの発見を振り返る」と表示し、NEXT CONNECTIONという英文ラベルを外す。
- 公式の入手情報リンクがある場合だけ、副次的なリンクとして押せる見た目に変更。未確認の商品では購入可能と表示しない。
- 参考用Instagramリンクは「紹介元のInstagram投稿を見る」と明記し、販売情報の最新性は保証しない旨を下部の小さな注意書きにまとめた。
- 商品詳細での保存操作は **ボタンの文言と aria-pressed のみ更新**。詳細パネル全体を再描画しない。保存一覧の削除は従来どおり一覧を更新する。
- 既存5商品、イラスト、商品順、左右スワイプ、固定商品ID保存、ショップの入手方法、初回ガイドなどは変更しない。
