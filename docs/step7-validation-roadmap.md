# STEP 7-3｜実証計画と応募までのロードマップ

作成日：2026-11-10
状態：**実行計画案**。実証・協業・契約の実施確約ではない。

## 基本方針
- 事業の中心は無料のMATCHA ROUTE Web。発見・詳細・保存のMVPを応募時の実装成果として示す。
- 収益はSTEP 6-4で決定した**B案（POP-UP物販とWeb送客収益を並行検討）**を維持。
- 応募前にPOP-UPや提携契約を成立させることは必須にしない。
- 実装済み機能／未実装機能、実績／仮定、提案／契約済み事項を明確に分ける。
- 正式なユーザーテストの実施は応募前の必須条件にしない（既存方針）。

## 3段階のロードマップ
### Phase 1｜応募準備（2026-11-10〜2026-12-11）
事業の提供価値、利用者・作り手・丸井の役割、競合との差、Webデモ、POP-UPの構想、収支シナリオを応募用に整理する。応募フォームの詳細要件・資格・文字数制限・提出形式を正式に確認する。

### Phase 2｜小規模実証（関係者の合意・必要条件が整った後）
- Web：商品閲覧、外部購入先への任意遷移、商品への関心をプライバシーに配慮して検証。成果報酬契約がない段階は収益0円として扱う。
- POP-UP：展示10商品・販売候補3商品を基本構想とするが、写真利用許諾、仕入、衛生・温度管理、会場条件に応じて縮小・変更する。
- 費用・人員・販売主体・責任分界・中止条件を事前に確認し、実施可能な規模だけで行う。

### Phase 3｜事業化判断（実証後）
Web送客の契約可否、商品への関心、運営費、POP-UPの損益、商品事業者の評価を基に、継続・改善・縮小・中止を判断。定期開催・オンライン販売連携は未決定。

## 実証の評価観点（数値目標は未決定）
- Web：閲覧・商品詳細への関心、外部ショップへの遷移、使いやすさ
- 収益：成果報酬契約の成立可能性、承認成果、運営費
- POP-UP：来場者の反応、購入件数、売上・粗利・廃棄・必要人員
- 作り手：掲載内容の妥当性、新しい顧客との接点
- 丸井：来店動機・館内導線・運営負荷
実証前に計測方法・同意・費用上限・撤退条件を定義する。

## リスク・次の作業
- 公式応募フォームの年齢要件・詳細設問・提出形式を確認する。
- 商品写真・名称・説明の権利、販売条件を確認する。
- 収支試算は費用見積もりではない。人件費・開発費・初期費用を追加して再計算する。
- 次STEP：応募用の事業ストーリーを「好き→発見体験→三者の価値→丸井の資産→収益→検証」の順でまとめる。
